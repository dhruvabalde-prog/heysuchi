# HeySuchi

HeySuchi is a mobile-first, voice-first operating system for getting things done.

## North star

Minimize human minutes required per completed outcome.

## Core loop

**Voice / Dump → Understand → Mission → Plan → Execute → Verify → Decision → Done**

## MVP

The first slice proves the Suchi Loop: capture an outcome, create a mission, show progress, and surface decisions instead of task lists.

## Stack

Next.js App Router + TypeScript. The architecture is intentionally provider-agnostic so model, browser, workspace, and automation providers can be added behind a single agent runtime.
